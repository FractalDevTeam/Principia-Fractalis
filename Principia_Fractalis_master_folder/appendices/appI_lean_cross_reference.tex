\section{Purpose}
\label{sec:lean-cross-reference-purpose}

This appendix is a one-row-per-chapter map from the manuscript's
principal claims to the Lean~4 theorems that machine-verify those
claims at HEAD commit \texttt{42990ea}. Where a Coq parity file
exists, it is indicated in the rightmost column.

\textbf{Reading this appendix:}
\begin{itemize}
\item \textbf{Column 1} (Chapter) names the manuscript chapter
or appendix.
\item \textbf{Column 2} (Principal Claim) summarises what that
chapter establishes.
\item \textbf{Column 3} (Lean Theorem) gives the exact Lean~4
theorem name (with its module path) that verifies the claim.
\item \textbf{Column 4} (Coq) is marked Y if a Coq parity file
mirrors the Lean theorem, --- if not.
\end{itemize}

\textbf{Honest scope:} as elsewhere in this manuscript, each Lean
theorem is axiom-free under
$[\texttt{propext}, \texttt{Classical.choice}, \texttt{Quot.sound}]$
(i.e.\ Lean's three foundational axioms; no project-level axiom is
invoked). Each per-axis theorem retains the individual honest scope
documented in its source file and in
Chapter~\ref{ch:substrate-theorem}'s
\S\ref{sec:substrate-honest-scope}. The substrate theorem of
Chapter~\ref{ch:substrate-theorem} bundles all the per-axis
theorems into one citable meta-theorem.

every entry of the cross-reference tables above is machine-checked
