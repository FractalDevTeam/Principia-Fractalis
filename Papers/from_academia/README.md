# Papers, brought under version control 2026-08-10

These were published to Academia.edu but were **not in any git repository**. They
lived only in `pablo_context/scientific_work/latex_documents/`,
`With Love for C and M/PDF's/`, `pablo_context/Context from Pablo/pdf/`, and
various `ARCHIVE/` trees. A disk failure would have lost them.

This was the largest data-preservation exposure in the setup — larger than the
171 orphaned Lean files, because those at least compile standalone and are
reproducible from source. These are not.

Copied, not moved. Originals untouched.

## What this is and is not

This is preservation, not endorsement. Several of these papers contain claims
that the machine-checked corpus has since refuted — see
`codex/AUDIT_RESPONSE_2026-08-06.md`, `codex/STEELMAN_2026-08-06.md`, and
`codex/COSMOLOGY_W_BRIDGE_2026-08-10.md`. They are versioned here so the record
is complete and the history is auditable, in the same additive spirit as the
chapter ledgers: nothing removed, corrections recorded alongside.

The Academia.edu listing carries 28 titles; some are duplicates of the same work
and a few (e.g. the non-mathematical essays) are not included here.
