\section*{Coq honesty pass (Contracts layer)}

In rev~2 a referee-disclosure pass was added to the Coq
\texttt{Contracts/} layer. Each ``Theorem'' that establishes a
Millennium-Problem proposition (\texttt{PF\_NS\_Solution} in
\texttt{NavierStokes.v}, \texttt{PF\_Hodge\_Conjecture} in
\texttt{Hodge.v}) and each ``Theorem'' that wraps an underlying
\texttt{Axiom} (\texttt{RH\_T3\_self\_adjoint},
\texttt{RH\_T3\_compact} in \texttt{RH.v}) now carries a prominent
in-source comment block stating: (i) the theorem is conditional, (ii)
which local axioms its proof depends on, (iii) the
\texttt{Print Assumptions} command that recovers the full dependency
list, and (iv) the cross-reference to the corresponding manuscript
chapter. No proofs were modified; the Coq build still completes
cleanly.
The corresponding machine-checked artefacts are in the Lean 4 source at
\texttt{PF\_Lean4\_Code/PF/} on the repository master branch.

The canonical source of truth for all claims above is the GitHub repository
\texttt{FractalDevTeam/Principia-Fractalis}, at or after commit \texttt{88d5f37}.
Foundational infrastructure for the eventual elimination of
\texttt{LogWeightedL2.inner} and \texttt{T3\_self\_adjoint\_conj} has now been laid
in \texttt{PF/LogWeightedIntegral.lean}: the log-weighted measure
$\mu := \mathrm{volume.withDensity}(1/x)$ is defined via mathlib's
\texttt{Measure.withDensity}, the supporting \texttt{SigmaFinite} instance is
machine-checked, and the concrete Hilbert space
\texttt{LogWeightedL2\_concrete := MeasureTheory.Lp $\mathbb{C}$ 2 logWeightedMeasure}
is in scope and inherits its inner product from mathlib automatically. The remaining
work to retire the two axioms is (a) refactoring \texttt{PF/TransferOperator.lean}
to use this concrete type in place of the current placeholder \texttt{structure},
and (b) supplying the kernel-symmetry calculation that the pen-and-paper proof of
Theorem~20.2 currently leaves implicit.
A detailed audit table (topic-by-topic axiom counts in Lean~4 vs Coq vs Lean4Lean)
is maintained at \texttt{PARITY\_REPORT.md} in the repository root.
