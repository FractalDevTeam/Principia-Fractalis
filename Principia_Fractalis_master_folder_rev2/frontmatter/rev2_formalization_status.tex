\section*{⚠ Verification check pending V01 reconciliation (2026-04-27)}

In a verification pass conducted after the rev~2 frontmatter above was
written, a numerical/symbolic computation applied to the operator and
inner product as transcribed verbatim from Chapter~20 and the Lean
source did not confirm the self-adjointness identity claimed in
Chapter~20 Theorem~20.2 under the standard reading of the transcribed
conventions on $L^2([0,1], dx/x)$. \textbf{This is not a finding that
the underlying mathematics is incorrect.} Pabs's earlier verification
work (the ``V01 catalog'') on this material is being located on disk
and the verification setup will be reconciled against it; until that
reconciliation completes, this remark documents an open verification
question rather than a confirmed inconsistency.

What the verification setup observed (using the operator and inner
product as transcribed verbatim, with no convention adjustment):
\begin{itemize}
\item Numerical: $\langle \tilde{T}_3 x, x\rangle \approx -0.110 + 0.162\,i$
      under the verified setup (a self-adjoint operator should yield
      a real diagonal under the same setup);
      $\langle \tilde{T}_3 f, g\rangle - \langle f, \tilde{T}_3 g\rangle
       \approx 0.096 + 0.188\,i$ for $f=x$, $g=x^2$ (40-digit precision).
\item A reconciliation pass tested nine alternative readings of the
      manuscript notation (alternative weight, alternative inner-product
      conjugation slot, alternative phase placement, several alternative
      Hilbert-space structures, etc.); none of those readings rescued
      self-adjointness under the verified setup.
\end{itemize}

What this does NOT establish:
\begin{itemize}
\item It does not establish that the Principia Fractalis derivation is
      mathematically wrong. The verification setup uses the manuscript
      notation as currently transcribed; if the original V01 derivation
      uses any aspect of operator definition, inner-product convention,
      Hilbert-space structure, or phase placement that differs from
      the transcription, the verification result above does not apply.
\item Pabs's V01 catalog (the cataloged record of the original
      verification work) has not yet been located on disk; once it is,
      the verification setup will be reconciled against it. Resolution
      will fall in one of three buckets: (i) V01 conventions match the
      transcription and the open question is real, (ii) V01 conventions
      differ from the transcription in a way that restores self-adjointness
      and the open question dissolves, or (iii) a small refinement of
      the manuscript transcription brings it into alignment with V01.
\end{itemize}

\textbf{What this revision does for now}:

\begin{itemize}
\item The Lean axiom \texttt{T3\_self\_adjoint\_conj} (PF/TransferOperator.lean:221)
      is retained in source. Its docstring carries an open-verification-question
      note pending V01 reconciliation. Downstream proofs in
      \texttt{SpectralBijection.lean} continue to typecheck and remain
      inspectable.
\item The numerical evidence reported in Chapter~20 \S20.5--20.6
      (eigenvalue tabulation, 150-digit verification, the
      $\alpha^* = 5 \times 10^{-6}$ fit) is unchanged in this revision.
      If V01 reconciliation surfaces a refinement to the operator
      definition, the numerical evidence will be re-run against the
      reconciled operator.
\item Recovery options under investigation: (a) symmetrize via
      $(T+T^*)/2$, (b) augment with expanding-direction branches
      $y_k^{-1}(x) = bx - k$, (c) change measure to one for which
      the inverse-branch maps form a unitary representation
      (e.g.\ Gauss measure for the Gauss map), (d) downgrade
      Theorem~20.2 to a conjecture and restate the chapter's
      RH connection as a research program. Each of (a)--(c) is a
      structural redesign; the bibliography hint is the
      Lapidus/Mayer/Connes lineage.
\item This finding was caught \emph{by} the rev~2 rigor pass; in
      particular, by the very kind of independent verification the
      rev~2 frontmatter committed to. The other 7 axioms in the
      Lean canonical library are unaffected; build remains clean
      (\texttt{lake build}: 5486 jobs, zero errors, zero
      \texttt{sorry}).
\end{itemize}

\section*{Lean4Lean layer (formerly \texttt{PF\_L4L/}, now quarantined)}

A skeletal Lean4Lean meta-verification layer was begun in earlier
revisions, but it was never made to build (the package required a
canonical-source directory that does not exist in the current repo
layout, and the imports it expects do not match the current Lean
file structure). To avoid misleading a referee with a non-buildable
``third formalization layer,'' the directory has been moved to
\texttt{experimental/PF\_L4L\_future/} and is \textbf{not} part of
the rev~2 claim. Restoring it to a working state would require
either restructuring the Lean code organization or rewriting the
L4L imports against the current layout; both are tracked as future
work in \texttt{RESEARCH\_ROADMAP.md}.
