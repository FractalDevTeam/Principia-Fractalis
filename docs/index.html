Chapter 2: A Different Way to Count

We humans usually count in tens (0-9). But what if we only used three symbols: 0, 1, and 2?

Then counting would go: 0, 1, 2, 10, 11, 12, 20, 21, 22, 100...

This is called Base-3!

Here's the magical part: we can add up the digits of any number. In base-3, we call this D₃(n) - the "digital sum."

For example: 14 in base-3 is "112" (1+1+2 = 4). So D₃(14) = 4!

This simple function reveals fractal patterns - patterns that repeat at every scale, like the branches of a tree or the coastline of an island.
