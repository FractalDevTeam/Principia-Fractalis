**Principia Fractalis** is Pablo Cohen's research program: a substrate
framework (the timeless field T∞, a UHF/Glimm 3^∞ C\*-algebra) projecting
into multiple mathematical and physical domains at characteristic
"resonance" values α. The corpus comprises a ~35-chapter book, a large
Lean 4 formalization (1,150+ files), a Rocq/Coq layer, and papers.

gaps with real mathematics. That separation has been done honestly, and

## 4. WHAT IS **NOT** PROVED (state this clearly to anyone)

Being precise here is what makes §3 credible.

- **No Millennium Problem is solved.** Not RH, not P vs NP, not BSD, not
  Navier–Stokes, not Yang–Mills, not Hodge.
- **No rank *equality*** — everything in §3e is a rank **lower** bound.
  Upper bounds need descent machinery that exists in no prover.
- **No L-functions.** mathlib has a formal Dirichlet series for elliptic
  curves (master only, not our pin) with *no* analytic continuation. The
  corpus defines no analytic rank.
- **Gross–Zagier / Kolyvagin / Heegner point theory: formalized nowhere
  on Earth.** Encoding their statements unproved would put them in
  `#print axioms` as assumptions — exactly what this project refuses.
- **Modularity:** Buzzard's FLT project targets an FLT-sufficient
  modularity lifting theorem, not full modularity; multi-year.
- **The α-values are not derived from the substrate.** r123 established
  M_{3^∞}'s K-theory is ℤ[1/3] (purely 3-adic) while the α's are 2-adic
  and 5-adic. r128 proves *rigidity given laws*, not derivation.
- **α_NP = φ+¼ is asserted, not derived** — the corpus's "IBM validation"
  of it is a `rfl` comparing a definition with itself
  (`memory/alpha-np-circular.md`).
- **The Extremal-Trace Conjecture (corpus's #1 open problem) is FALSE** —
  it claims nine extremal traces; r113 proves exactly one.
- **ch24's Rank Formula did not reproduce** under independent numerical
  test (`codex/CH24_SPECTRAL_TEST_2026-07-28.md`). BUT — see §7.

## 7. A GENUINE FINDING WORTH PURSUING (ch24)

Independent numerical test of the book's BSD spectral operator 𝒯_E
(`codex/CH24_SPECTRAL_TEST_2026-07-28.md`), run against four curves whose
ranks are now *kernel facts*:

- The stated **Rank Formula** (multiplicity of eigenvalue φ/e = rank) did
  **not** reproduce: multiplicities 3, 11, 3, 10 for ranks 0, 1, 2, 3.
- But the operator's **dominant eigenvalue is monotone in rank**, at
  ≈ +2 per rank: 0.32 (r=0), 2.57 (r=1), 4.48 (r=2), 6.49 (r=3).

That second signal aligns with the classical **Mestre–Nagao** phenomenon
(a_p/p-weighted sums encoding rank, conditionally on BSD). The book's core
intuition — *rank is spectrally readable from a_p data* — has a real
footprint; the φ/e coordinate was the wrong place to look. Robustness in
prime cutoff and grid size is untested and should be the first follow-up.

## 8. THE STANDARD (do not compromise it)

Every stone in §3 exists because of this loop:

1. **sympy-verify every identity numerically/symbolically BEFORE writing Lean**
   (this produced ten consecutive first-pass-clean files)
2. write the Lean; compile with `lake env lean` on the single file
3. **independently rebuild** — never trust the writer's own report
4. grep for `sorry` / `native_decide`; check transitive `#print axioms`
5. register the import in `PF.lean`; full `lake build PF`
6. commit with a message stating exactly what was and wasn't proved
7. **push immediately** — a laptop crash mid-session cost zero work

Note: `#print axioms` output from a *failing* build is meaningless
(`sorryAx` appears via error recovery). Always check for errors first.

Every file carries an **HONEST SCOPE** block naming what it does not
establish. This is not modesty; it is what makes the strong claims
survivable.
