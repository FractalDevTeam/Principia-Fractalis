CONCLUSION: try the manuscript's OWN form on its OWN terms

Ch 3 Thm 'Polylog Evaluation':
   R_f(alpha, 1) = Li_1(e^{i*pi*alpha}) * Phi(alpha) = pi*alpha/10 + O(alpha^2)

This statement REQUIRES  Li_1(e^{i*pi*alpha}) * Phi(alpha)  to be FINITE and
ANALYTIC near alpha = 0 with Taylor coefficient pi/10 in alpha.

But  Li_1(e^{i*pi*alpha}) = -log(-i*pi*alpha + ...) BLOWS UP logarithmically
at alpha = 0.   So for the product to be analytic and ~ pi*alpha/10, we'd need
   Phi(alpha) = pi*alpha / (10 * Li_1(e^{i*pi*alpha}))
which means Phi -> 0 as alpha -> 0 (logarithmically).   The MEASURED Phi(alpha)
does NOT satisfy this — measured Phi tends to a finite nontrivial value.

So the manuscript theorem as stated is internally inconsistent regardless of
whether the leading order is pi*alpha/10 or pi/(10*alpha).
