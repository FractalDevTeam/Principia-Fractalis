## §9.1 — Generalized elementary theta term (LANDED 2026-08-26)

Adapts r315's fixed `thetaTerm` (critical-line, exponent -3/4) to σ-family:

```
thetaPowCosTerm a t n u = u^a · cos((t/2) log u) · exp(-π(n+1)²u)
thetaPowSinTerm a t n u = u^a · sin((t/2) log u) · exp(-π(n+1)²u)
```

Landed theorems (all kernel-clean `[propext, Classical.choice, Quot.sound]`):

* `thetaPowCosTermD1`, `thetaPowSinTermD1`, `thetaPowCosTermD2`, `thetaPowSinTermD2` — explicit Leibniz-expansion derivatives
* `hasDerivAt_thetaPowCosTerm`, `hasDerivAt_thetaPowSinTerm` — first derivative correctness
* `hasDerivAt_thetaPowCosTermD1`, `hasDerivAt_thetaPowSinTermD1` — second derivative correctness
* Six private factor bounds: `abs_powP_le_one`, `abs_powP_D1_le`, `abs_powP_D2_le`, `abs_Qcos_le_one`, `abs_Qsin_le_one`, `abs_Qcos_D1_le`, `abs_Qsin_D1_le`, `abs_Qcos_D2_le`, `abs_Qsin_D2_le`, `abs_R_le`, `abs_R_D1_le`, `abs_R_D2_le`
* `thetaPowTermM` — closed-form uniform `C²` bound constant
* `abs_thetaPowCosTermD2_le`, `abs_thetaPowSinTermD2_le` — six-term Leibniz bound

**M formula:**
```
thetaPowTermM t p1 p2 L n =
  exp(-π(n+1)²·L) · (p2 + (|t|/2 + (t/2)²) + (π(n+1)²)²
                     + 2p1·(|t|/2) + 2p1·(π(n+1)²)
                     + 2·(|t|/2)·(π(n+1)²))
```

At t=15, p1=25/32, p2=1425/1024 (box 0 exponent range), and L=1: per-elementary-term `thetaPowTermM 15 (25/32) (1425/1024) 1 0 ≈ 5.99`. Summed over n<3 and multiplied by 2 (for the two exponent branches a₁, a₂):

  `M_Re(L) = 2·Σ_{n<3} thetaPowTermM 15 (25/32) (1425/1024) L n ≈ 12` at L=1.

This is the **per-coordinate** bound — same value applies to `M_Im(L)` via triangle inequality on `S_{a₁,n} - S_{a₂,n}`. We do **NOT** add M_Re + M_Im (that would give the wrong 24 and destroy the OPT-40-TIGHT budget). The smoke test's `Msegment(1) ≈ 12` matches the M we feed to `composite_midpoint_error` separately for Re and separately for Im.
