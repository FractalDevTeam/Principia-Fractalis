# Wallstrom from nodal topology: the lattice IS ℤ, and smoothness of ρ forces it

**Date:** 2026-10-16 (Legion). No Lean. **This is a partial positive — the
first in this lane.** Labels FACT / ARITHMETIC / JUDGEMENT / OPEN throughout.

**Headline.** Unlike base-3, the nodal route supplies the **right group**:
`H¹(supp ρ \ nodes; ℤ) ≅ ℤ^k`. And circulation quantization **does** follow,
from a regularity condition on the matter density alone — **`ρ` smooth across
its own nodal set forces `∮ m v·dl ∈ 2πħℤ`**. Finite energy does *not*.
One genuine gap survives: `H¹` of **geometric** origin (ring, Aharonov-Bohm,
multiply-connected domains), where `ρ > 0` and smoothness says nothing.

---

## 1. Topology of the nodal set — FACT (classical)

For `ψ : ℝ³ → ℂ` generic, `{ψ = 0} = {Re ψ = 0} ∩ {Im ψ = 0}` is a transverse
intersection of two codimension-1 surfaces, hence **codimension 2**: a
1-manifold — **nodal lines** (Dirac 1931; Nye-Berry 1974 "wavefunction
dislocations"). In 2D they are isolated points.

Working directly with Madelung data: the node set is `N = {ρ = 0}` and
`M = supp ρ \ N`. For `N ⊂ S³` a link with `k` components, Alexander duality
gives

  `H¹(S³ \ N; ℤ) ≅ ℤ^k`,

generated by small meridian loops, one encircling each nodal component.
**FACT.**

**When is it nontrivial?** Exactly when `ρ` has a codimension-2 node set.
Note the structural match, which is in the theory's favour:

* **nodeless states** (`ρ > 0`, e.g. a ground state): `M` is simply connected,
  `H¹ = 0`, so `∮ = 0` is forced automatically and the quantization condition
  is **vacuous** — correctly, since these are the zero-angular-momentum
  states;
* **vortex / excited states**: `H¹ = ℤ^k`, one generator per nodal line, and
  the circulation classes are exactly the angular-momentum degrees of
  freedom.

So the `H¹` appears precisely where it is needed and vanishes precisely where
it must. **JUDGEMENT:** this is a point in the route's favour that the base-3
attempt could not even formulate.

## 2. Is the lattice ℤ, or denser? — **ℤ.** FACT

`H¹(M; ℤ) ≅ ℤ^k` maps into `H¹(M; ℝ) ≅ ℝ^k` with image the standard lattice
`ℤ^k`. This is the decisive contrast with the substrate route, whose only
available integrality was `ℤ[1/3]` — **dense in ℝ, hence not a lattice at
all** (`WALLSTROM_BASE3_REFUTED_2026-10-16.md`). Here the group is right on
the nose.

**But a lattice existing is necessary, not sufficient.** `[θ] = [(m/ħ)v♭]` is
*some* point of `ℝ^k`; topology provides the lattice and does **not** place
`[θ]` in it. That is Wallstrom's objection, restated precisely. The content of
§3 is what puts it there.

## 3. What forces `[θ]` into ℤ — smoothness of ρ. The core result

### 3a. The Madelung system admits every real circulation — ARITHMETIC (verified)

Take a stationary axisymmetric state near a straight nodal line (cylindrical
`r, φ, z`), set `f = √ρ`, and let the circulation be parameterised by
`ℓ := m∮v·dl / (2πħ)`, so `v_φ = ħℓ/(mr)`. The quantum Hamilton-Jacobi
equation `(m/2)v² + V + Q = E` with `Q = -(ħ²/2m)(f'' + f'/r)/f` reduces to

  `f'' + f'/r - (ℓ²/r²) f = (2m/ħ²)(V - E) f`.

With `V - E` regular the leading behaviour is the indicial one. Verified
symbolically: the general solution of the leading-order equation is
`f = C₁ r^{-ℓ} + C₂ r^{ℓ}`, so the regular branch is

  `f ~ r^ℓ`,  i.e.  **`ρ ~ r^{2ℓ} = (x² + y²)^ℓ`**,

and **`ℓ` is a free real parameter** — the ODE is well-posed for every real
`ℓ`. These are exactly Wallstrom's unwanted solutions, made explicit: smooth
wherever `ρ > 0`, satisfying Madelung exactly, with `ψ = √ρ e^{iℓφ}`
multivalued for `ℓ ∉ ℤ`.

### 3b. Finite energy does NOT exclude them — ARITHMETIC (verified)

With `ρ ~ r^{2a}` and `|v| ~ 1/r`, the kinetic term integrates as
`∫₀¹ r^{2a-2}·r\,dr = 1/(2a)`, finite for every `a > 0`. The quantum-potential
term has the same scaling (`(f''+f'/r)/f = a²/r²` for `f = r^a`) and likewise
converges. **Both energy terms are finite for any `a > 0`, integer or not.**
So the common hope that finite energy forces quantization fails.

### 3c. Smoothness of ρ DOES exclude them — ARITHMETIC (verified) + JUDGEMENT

**Lemma (verified symbolically).** `(x² + y²)^a` is `C^∞` at the origin **iff**
`a` is a non-negative integer. Checked by two-sided derivative limits along
`y = 0`:

| `a` | first failing derivative | limits `x→0⁺` / `x→0⁻` |
|---|---|---|
| 1/2 | `∂¹_x` | `+1` / `−1` — not even `C¹` |
| 1 | — | polynomial, `C^∞` |
| 3/2 | `∂³_x` | `+6` / `−6` — `C²` but not `C³` |
| 2 | — | polynomial, `C^∞` |
| 5/2 | `∂⁵_x` | `+120` / `−120` |
| 3 | — | polynomial, `C^∞` |

Combining with 3a: `ρ ~ (x²+y²)^ℓ` near a nodal line, so

> **`ρ ∈ C^∞` across its own nodal set ⟹ `ℓ ∈ ℤ₊` ⟹ `∮ m v·dl ∈ 2πħℤ`.**

**Why this is not circular.** The hypothesis is a regularity condition on
`ρ` — the diffusion's own density, an observable, the object gap 2 produces.
It is **not** the assumption that a single-valued `ψ` exists. So Wallstrom's
condition is *reduced* to a smoothness axiom on the matter density, which is a
strictly weaker and more natural input. **JUDGEMENT**, and the central claim
of this note.

### 3d. Where it does not reach — OPEN

**Geometrically generated `H¹`.** If the configuration space is itself
multiply connected with `ρ > 0` throughout — a particle on a ring, an
Aharonov-Bohm geometry, any excluded-region domain — then `H¹ ≅ ℤ` comes from
the *geometry*, there is no node, `ρ` is smooth and positive, and **3c says
nothing**. Non-integer circulation is then unobstructed by anything in
`(ρ, v)`. **Wallstrom's objection survives intact in this sector.**

This is a real residual gap, not a technicality: the ring is the textbook
first example of angular-momentum quantization.

**Three further caveats, stated rather than buried.**

1. The local analysis in 3a is for an **axisymmetric straight** nodal line.
   At a generic nodal point the leading local model should still be a power of
   the distance to the line times a smooth positive factor, giving the same
   conclusion — but that needs a proper local normal-form argument, which I
   have not done. **OPEN (technical).**
2. `ρ` vanishing to **infinite order** (e.g. `e^{-1/r}`) escapes the lemma.
   Plugging `f = e^{-1/2r}` into 3a's ODE forces `V - E ~ r^{-4}`, so for any
   regular or Coulomb potential this branch is unavailable — **JUDGEMENT**, by
   inspection of the ODE, not proved in general.
3. Whether "`ρ` smooth **at** the nodes" is a legitimate axiom is arguable. A
   referee can reasonably say the hydrodynamic description degenerates exactly
   where `ρ = 0`, so imposing smoothness there is where the physics is being
   put in. I think it is a fair and weak assumption — `ρ` is a density, not a
   phase — but it is an assumption, and the result should always be stated
   with it attached.

## 4. Verdict

**Test result: the nodal route passes, in the node-generated sector, and fails
in the geometric sector.**

* the group is **ℤ**, exactly as needed — FACT;
* `H¹` is nontrivial precisely for the states that need circulation — FACT;
* quantization **follows** from smoothness of `ρ`, not from energy — ARITHMETIC
  + JUDGEMENT;
* **but** circulation generated by configuration-space topology rather than by
  nodes is untouched — OPEN.

So the Nelson route does **not** need geometric quantization for the nodal
sector; it still needs something for the ring/Aharonov-Bohm sector. That is a
much smaller and sharper hole than Wallstrom in general, and it is the next
thing to attack if this lane continues.

**Method note worth keeping.** My first run of the §3c test restricted to
`y = 0, x → 0⁺`, where `(x²+y²)^a = x^{2a}` and the conical singularity is

nodal route fails. The corrected test uses two-sided limits. One-sided probes
of a radial singularity are worthless.
