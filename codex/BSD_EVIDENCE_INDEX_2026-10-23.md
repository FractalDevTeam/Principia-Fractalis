# BSD lane — evidence index (theorem → commit → axiom output location)

**Legion, 2026-10-23.** Companion to `codex/RIEMANN_EVIDENCE_INDEX_2026-10-23.md`,
for Rio's P8, which asks each lane for an index at this shape. Generated by
`codex/build_bsd_index.py` from the committed tree.

## Scope rule

A declaration is listed only if its file carries a `#print axioms` line naming
it. That is the corpus's own marker for "load-bearing claim whose axiom set was
checked", so the index inherits the corpus's judgement about what counts rather
than mine.

## The finding this index exists to surface

**74 files, 524 axiom-checked declarations. The axiom output is recorded
somewhere for 54 of the 74 — and for 20 it is recorded nowhere.**

| where the axiom output lives | files |
|---|---|
| commit message only | 33 |
| status board + commit message | 19 |
| status board only | 2 |
| **NOWHERE — needs a rebuild to produce it** | **20** |

`#print axioms` prints at **build time**; its output is not in the tree. So for
those 20 files the dossier cannot cite an axiom result from anything committed —
it would have to rebuild them. Several are load-bearing universal layers, not
peripheral:

- `DuplicationSizeUniversal_r175` (3 decls) — supplies `CL`, the constant the
  whole duplication height bound is stated against
- `RankPipelineUniversal_r202` (6 decls) — the universal rank pipeline
- `SecantSizeLower_r197`, `SecantUpperWindow_r198`, `SecantSizeUniversal_r193`,
  `SecantContentUniversal_r196`, `SecantUniversal_r181` — the secant layer
- `BSD_HeegnerRank1ProofE43a1`, `BSD_HeegnerRank1ProofE91a1` (12 decls each)
- `MordellWeilRankAgreement17` (12 decls)

**This is not a claim that any of them is unsound.** It is a claim about
*evidence location*: nothing committed records what their axiom check printed.
The remedy is a rebuild with the transcript captured — which is exactly what
`codex/ci_gate_audit_transcript.py` was written to parse, and it needs no new
machinery, only one build each under the shared lock.

**Priority if the dossier needs them:** r175 and r202 first, since the E91a1
capstone's `1 ≤ Module.rank` chain runs through both, and that capstone's own
axiom output *is* on the board verbatim. An index that records the capstone at
full strength while two of its dependencies have no recorded axiom output is
exactly the kind of gap P8 should catch before a referee does.
