# Riemann march — evidence index (theorem → commit → gate)

**Legion, 2026-10-23.** Built for Rio's P8 dossier, which asks each lane for an
evidence index at exactly this shape. Generated by
`codex/build_evidence_index.py` from **the committed tree only** — no `/tmp`
logs, which are ephemeral and already gone for the early boxes.

## What each column is sourced from, and what it is not

| column | source |
|---|---|
| interval | the capstone's own `Icc` statement, read out of the committed file |
| theorem | the capstone's name, same source |
| commit | `git log` for that path |
| gate recorded | whether the landing commit message carries the gate result |
| thms | the theorem count the gate recorded, where present |
| contraband | a **fresh** scan of the committed bytes for `sorry` / `native_decide` / `sorryAx`, excluding each file's own discipline docstring |

**The `#print axioms` output itself is not in the tree** — it prints at build
time. So this index does not and cannot assert the axiom output from the bytes.
It records two separable things: what the gate recorded when the box landed, and
what the committed bytes contain now. Anyone wanting the axiom output must
rebuild, which is what `codex/ci_gate_audit_transcript.py` is for.

## The honest gap

**35 of 46 landing commits carry the gate result. 11 do not.** Those 11 are the
early hand-built boxes that predate the schedule runner and its axiom gate;
their files carry the three-axiom-bar claim in their own header docstrings, and
they pass the independent contraband scan, but *the gate output is not in their
commit*. That is a weaker evidence tier than the 35, and it is listed as such
rather than averaged in.

**46 of 46 are contraband-free** on the independent scan.
