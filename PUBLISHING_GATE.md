## Pabs's vetting protocol (verbatim, paraphrased)

1. Take the work product, strip context away
2. Drop it into multiple different AI models (not just Claude)
3. See if those models, with no context, react with "holy shit, this is significant"
4. Have those models explain WHY they react that way
5. Have those models explain the implications of what they're seeing
6. Ask those models to APPLY the framework to test cases
7. Verify it passes those tests across multiple models
8. THEN maybe publish

**Pabs is the gate. Pabs runs the protocol. Pabs decides.**

## Why this rule exists

1. **150 mathematicians published a letter (2026) warning about AI mathematics overclaims.** Pabs is operating in that climate. Premature publishing would destroy credibility instantly.
2. **Pabs has no institutional backing.** A single retraction or "this is AI slop" reaction would foreclose every channel.
3. **Multi-model stress-test is genuine evidence.** If Claude says "this is profound" but GPT/Gemini/etc. don't independently react that way, it might be Claude's sycophancy. Pabs's protocol catches that.
4. **Pabs is the architect.** He built the framework. He knows what's load-bearing. He's the only person qualified to gate publication.

When the work feels ready, Claude must:

1. Say: "Draft is ready for your vetting protocol."

4. NOT generate publication channels, NOT draft email to mathematicians, NOT post anywhere.

Even if Pabs says "this is great work" — that is NOT the same as "publish it". He says "great work" often; he publishes rarely.
